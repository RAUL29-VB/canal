# Estudio Cine 3D Misterio

Motor de animación 3D Cel-Shaded para producción de videos de misterio en YouTube, TikTok y Facebook en resolución Full HD 1080p.

## Características

- **Formatos soportados**:
  - YouTube Largo 16:9 (Full HD 1920x1080)
  - YouTube Short 9:16 (Full HD 1080x1920)
  - Facebook / TikTok Completo 9:16 (Full HD 1080x1920)
- **Motor 3D**: Renderizado en Three.js con cel-shading estilizado.
- **Interactivo**: Escenarios, cámaras cinemáticas, personajes y sincronización de subtítulos/voz.
- **Generación de voz y efectos**: Motor de audio y narración.

## Cómo ejecutar

Abre el archivo `ABRIR_ESTUDIO.bat` o abre `index.html` en un navegador web.
